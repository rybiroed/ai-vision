Identity rules

Six rules against wrong names

Decide per segment

A tracker swap in a crossing can’t carry a confirmed ID onto someone else.

Joint assignment

Everyone on screen is matched together, never nearest-first.

Clear margin

The best candidate must clearly beat the second, otherwise UNKNOWN.

One ID, one person

A player confirmed on screen is never given to a second person.

LOST is not seen

Predicted positions are marked as predictions, never as observations.

Second pass

Later clear frames fix earlier fragments; the first decision stays in the log.

Шесть правил, которые не дают назвать игрока чужим именем. Решение принимается по отрезку траектории, а не по всей траектории. Всех видимых людей сопоставляем одновременно. Лучший кандидат должен заметно опережать второго, иначе ставим «неизвестно». Один ID не может быть у двух людей сразу. Прогноз положения не выдаётся за наблюдение. А второй проход по записи может исправить ранний фрагмент по более поздним кадрам, при этом исходное решение сохраняется в журнале.
