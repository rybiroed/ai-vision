Software, models and methods

Software

  • Python 3.11, Bash, HTML/JS
  • ONNX Runtime 1.30 — runs all networks
  • OpenCV 5.0 — video, ORB, drawing
  • NumPy 2.4 · SciPy 1.17 — maths
  • Flask 3.1 — local web interface
  • Pillow 12.3 · RapidOCR 1.4 · pytest 9.1
  • ffmpeg / ffprobe · git · curl

Models (all Apache-2.0)

  • YOLOX-m (Megvii) — people and ball
  • YoutuReID (OpenCV Zoo) — appearance
  • PP-OCR via RapidOCR — numbers
  • YOLOX-s — tested as a faster option

Methods (own code)

  • ByteTrack-style tracking
  • Kalman filter
  • ORB + RANSAC camera motion
  • Hungarian assignment
  • Logistic score model
  • IDF1 and identity metrics
  • Pinhole distance estimate
Чем пользовались, часть первая. Всё написано на Python. Нейросети запускаются через ONNX Runtime, видео обрабатывается через OpenCV, математика — NumPy и SciPy, интерфейс — Flask, для видео ffmpeg. Модели: YOLOX для людей и мяча, YoutuReID для внешности, PP-OCR через RapidOCR для номеров, все с открытой лицензией Apache-2.0. Трекер, менеджер имён и метрики написаны с нуля, чтобы не брать код под лицензией AGPL. Полный список с версиями есть в docs/RESOURCES.md.
